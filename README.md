# Student Manager

Ứng dụng quản lý sinh viên — DevOps Lab 5

**Version 1.0.0** — Phát triển bởi Nhóm A & Nhóm B

## Tính năng

- Mô hình sinh viên (`Student`) và chuyển đổi sang dictionary.
- Thêm sinh viên, kiểm tra mã trùng (`add_student`).
- Tìm sinh viên theo tên hoặc mã, không phân biệt chữ hoa chữ thường (`search_student`).

## Chạy bằng Antigravity IDE

1. Mở thư mục dự án này trong Antigravity IDE.
2. Mở terminal tích hợp tại thư mục gốc.
3. Chạy `python src/main.py`.

Ứng dụng dùng Python 3, không cần cài thư viện ngoài hoặc Visual Studio.

## Git Flow

Lịch sử gồm `main`, `develop`, các nhánh `feature/*`, các merge commit và một lần giải quyết xung đột trong README. Xem bằng `git log --oneline --graph --all`.
